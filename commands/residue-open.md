---
description: 立项:声明项目产出目录,未结项期间副产物保留不清
---

为当前项目启动「AI 残渣清运」的项目制管理。执行以下步骤:

1. 向用户确认(或从对话推断)两件事:**产出目录名**(默认 `产出`)和**项目名**(可选)。产出目录是本次项目所有成品和中间产物的固定存放地。
2. 读取项目根的 `.ai-residue.json`(可能不存在),把 `project` 块写入/更新为:

```json
{
  "project": { "status": "open", "deliverables_dir": "产出" }
}
```

保留文件里已有的 `retention_days`、`extra_rules` 等其他键。然后创建产出目录(若不存在)。
3. 向用户说明立项后的行为变化:
   - 建议此后所有产物(成品和中间文件)都放进产出目录;
   - **未结项前插件不会自动清运**,副产物原地保留;
   - 产出目录始终受保护,常规清运永远不会碰它;
   - 结项时用 `/residue-close`:成品自动归类(文稿/视频成品/音频/图片/数据),副产物移入回收站,并生成《结项清理清单》文本文档。
